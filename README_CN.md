# CoQ 棋钟 · CoQ Chess & Weiqi Clock

[English](README.md) · **华文**

一台**摆在两位棋手之间、平放着用**的棋钟：整块半屏就是按键，谁走完棋就拍自己那一侧，不用瞄准小按钮。
纯 HTML5 + 原生 JavaScript，零依赖、零后端、**断网可用**；国际象棋与围棋通用 —— 围棋尤其合适，
Byoyomi 读秒本来就是围棋赛制。

> ### 📱 手机优先 —— 电脑是用来开发和测试的
>
> 这个产品就是**平放在两位棋手中间的一部手机**，为它准备的两个版本是**网页版**（本目录）和
> **Godot 版**（[`Godot/`](Godot/README.md)，会打成安卓 APK）。三个版本在电脑上当然都能跑
> （双击 `index.html`，或用对应的桌面版），自动化测试、截图流水线与日常开发也正是这么用的 ——
> 但请把电脑上的运行当作**开发者测试**，界面效果以手机为准。（裁判拿笔记本当记谱台，是唯一的非开发者例外。）

## 三个版本

同一台棋钟、三份实现，行为上保持同步 —— 另两份都由自动化测试逐项与网页版比对，不会各改各的：

| | 版本 | 技术 | 怎么装到手机上 | 自动化测试 |
| --- | --- | --- | --- | --- |
| **1** | **网页版** —— 本目录。**手机上先用这个。** | HTML5 + 原生 JS，无需构建，53 项测试 | 手机浏览器打开 →「添加到主屏幕」（不用安装、不过应用商店，首次加载后离线可用） | **基准实现**：另两版的常量 / 文案 / 预设 / 色值都以它为准逐项比对 |
| **2** | **Godot 4 版** —— [`Godot/`](Godot/README.md)。**安卓原生应用版。** | GDScript，Godot 4.5 | 自己打一次安卓 APK（步骤见 [`Godot/README.md`](Godot/README.md)，产物不入库） | **测试较充分**：引擎 31 用例（220 断言）+ 无头界面 21 用例（126 断言）+ 431 项对照 + 17 张截图 |
| **3** | **Defold 版** —— [`Defold/`](Defold/README.md) | Lua，Defold 1.13 | 用 Defold / `bob` 自行打包（Linux、Windows、macOS、Android、HTML5） | **三份里测试最少的**：引擎 31 + 设置 13 用例、20 项静态检查通过，但**没有无头界面测试套件** —— 界面靠截图 + 一次脚本化点击回归核对 |

**为什么先用网页版**：不用安装、不用签名，iPhone 与安卓都一样，更新就是拷一个文件夹。
**什么时候用 Godot 版**：你想要一个真正装在手机里的安卓 App（原生音效、屏幕常亮、返回键处理）。

**Godot 版的测试比 Defold 版更充分。** Godot 版有一套无头界面测试（真的把场景实例化出来并点击），
另有与网页版逐项比对的 431 项检查、17 张入库截图。Defold 版的引擎与设置测试都通过、截图也人工核对过，
但界面只跑过一次脚本化点击 —— 所以如果你要原生构建、又没有特别理由选 Defold，请选 Godot。
（两个移植版目前的 README 都是中文。）

界面**中英双语**：设置页右上角的 `ENG / 华文` 按钮随时切换，选择会记住（也可用 `index.html?lang=en` 直接指定）。

## 一、先看实体棋钟有什么：功能取舍依据

我按比赛用实体钟（DGT 2010 / Chronos / Garde 这一类）逐个对照，只保留"比赛真的会用到"的部分：

| 实体棋钟功能 | 本棋钟 | 说明 |
| --- | --- | --- |
| 适用棋类 | 国际象棋 + 围棋 | 读秒（Byoyomi）本就是围棋赛制；详见第四节的「围棋怎么用」 |
| 界面主题 | 浅色 / 中性 / 深色 | 设置页下拉框随时切换，选择会记住；见第七节的「界面主题」 |
| 双方独立倒计时、大字号显示 | ✅ | 数字按面板尺寸自动撑满，桌子对面也看得清 |
| 跷跷板按键：拍某一侧，停自己、走对方 | ✅ | **整块半屏都是按键**，手掌拍下去即可，不用瞄准小按钮。**开局也靠它**：没有「开始」按钮 |
| 走子换手逻辑（未走棋时按自己一侧无效） | ✅ | 与实体钟一致：按在非活动方不产生任何效果 |
| Fischer 加秒（每步走完立即加秒） | ✅ | 国际比赛最常用；与 Bronstein、无加秒共用同一组预设 |
| Byoyomi 读秒（主时间用完后每手重置 X 秒，可多段） | ✅ | **首次打开默认模式**；围棋 / 将棋 / 中国象棋的制式，见第四节 |
| Bronstein 延时（每步前 N 秒不计时） | ✅ | 适合初学者，慌张时不掉时间 |
| 无加秒（突然死亡） | ✅ | 最简模式，社区赛常用 |
| 旗倒判负（超时提示） | ✅ | 红字 + 警报声 + 震动 + 结果覆盖层 |
| 剩余时间告警 | ✅ | ≤1 分钟转黄，≤20 秒转红并显示 0.1 秒 |
| 读秒提示 | ✅ | 读秒阶段数字转紫、显示剩余段数，**数字与步数行之间还有一条分段指示条**（一段 = 一段读秒：**绿 = 还没用，红 = 已经用掉**；正在倒计时的那一段会按本窗口剩余比例由绿变红——20 秒的窗口剩 5 秒时，这一段 75% 红、25% 绿），最后 10 秒每秒滴答（主时间阶段同样如此，四种模式通用） |
| 步数计数 | ✅ | 每方面板显示已走步数 |
| 暂停 / 继续（裁判记谱、处理争议时用） | ✅ | 暂停会把这一手已用时间（含读秒段数）精确入账 |
| 复位 / 再来一局（自动交换先后手） | ✅ | 一局结束一键开下一局 |
| 声音开关 | ✅ | 走子提示音 + 超时警报（现场合成，无音频文件） |
| 双面朝向（两位选手对坐各看一面） | ✅ | 「对坐模式」（`180°`）把对面那块面板的数字转正；「交换两侧」（`⇵`）把双方换到另外半屏，见第五节 |
| 屏幕常亮 | ✅ | Wake Lock API，对局中不熄屏 |
| 可点击的 logo | ✅ | 设置页页头或操作条上的 logo 点一下换下一个：**TARUMT → CoQ → 国际象棋 → 围棋 → MWA** 循环，选择会记住 |
| 可替换的图标 / favicon | ✅ | 覆盖 `assets/logo-source.png` 后跑 `node tools/export-icons.js` 重出各尺寸，见第七节 |

## 二、怎么跑起来 —— 手机优先

### 方式 1：网页版放在手机上（这就是产品本身）

在电脑上（只是起个静态服务）：

```bash
node serve.js            # 默认 8080 端口；也可 PORT=8081 node serve.js
```

终端会打印出手机可访问的地址，例如：

```
棋钟已启动（同一 Wi-Fi 下的手机可直接访问）：
  本机：    http://localhost:8080/
  手机：    http://192.168.1.23:8080/
```

手机连同一个 Wi-Fi，浏览器输入那个 `192.168.x.x` 地址即可。
（若手机打不开，多半是 Windows 防火墙拦了 Node —— 首次运行会弹窗，选"允许专用网络"。）

> **只有第一次打开需要联网，之后就能离线用。** 手机第一次打开页面时要联网（把 `index.html`、`styles.css`、
> 三个脚本和图标素材下载一次）；页面一旦加载完成，整个棋钟都在本地运行 —— 不发任何网络请求、不依赖 CDN
> 或在线字体 —— 直接开飞行模式也能继续用。

### 方式 2：Godot 版装成安卓应用

**最快：直接下已经打包好的** [`CoQChessClock-debug.apk`](https://github.com/lots/ChessClock/releases/tag/v1.0.1)
（27.5 MB，调试签名），拷进手机点开装，或 `adb install -r CoQChessClock-debug.apk`。
想自己打也行：用 Godot 4.5 导出，命令见 [`Godot/README.md`](Godot/README.md)（**APK 是构建产物、不入库**，
所以仓库里没有这个文件）。同一台棋钟，但它是真正装在手机里的应用：原生音效、屏幕常亮、硬件返回键处理。
目前只出过安卓的包。

### 方式 3：把网页版托管到网上（选手用各自的手机打开）

整个目录都是静态文件，扔到任意静态托管即可，**不需要后端、不需要数据库**：

* GitHub Pages：把本目录推到仓库，Settings → Pages → 选分支根目录
* Netlify Drop：把文件夹直接拖到 <https://app.netlify.com/drop>
* Vercel / Cloudflare Pages：同上

### 方式 4：在电脑上（开发与测试）

直接双击 `index.html`，全部功能（含对坐旋转、声音、全屏）都可用，无需任何服务器。截图流水线、自动化
测试与日常开发就是这么跑的；裁判临时用笔记本顶一下也行 —— 但这台钟设计的舞台是桌上的手机。

### 手机上顺手做两件事（强烈建议）

1. **加到主屏幕**：手机浏览器菜单 →「添加到主屏幕」。这样打开没有地址栏，接近全屏，且可离线打开（文件已在本地缓存）。
2. **开飞行模式或免打扰**：比赛中来电会打断计时（见第六节）。

## 三、操作说明

### 比赛流程

1. 在设置页选好**计时模式**，再从第 2 张卡顶部的**下拉框**里挑**时间**（用预设即可；自己改过数字后，
   下拉框会自动落到最后一档「自定义」），点「开始对局」。设置页最下面还有一行 **「怎么用 ›」**，
   点进去是单独一页（摆放方式 / `180°` 说明与读秒入门），按 `Esc` 或页内的返回按钮回来。
2. 进入棋钟页——**没有「开始」按钮**：面板本身就是跷跷板，拍某一侧就停那一侧、走对侧。所以白先走的开局
   就**拍黑方那一半**，白方的钟立刻开始倒数；若该黑先走，就拍白方那一半（反之亦然）。这第一下**不算步数**。
3. 谁走完棋，就**拍自己那一侧的整块面板**，时间立刻交给对方。
4. 一方时间归零：立即停表、响警报、震动，弹出结果（"某某 超时 / 某某 获胜"）。
   → 「再来一局（交换先后手）」或「返回设置」。
5. 需要临时停表（记谱、处理争议）：点「停」，再点「续」（按钮上只写一个字，悬停提示与读屏软件念的是完整的「暂停 / 继续」）。这颗按钮只在开表之后才出现。

### 中间的操作条

| 按钮 | 作用 |
| --- | --- |
| `停` / `续` | 暂停 / 继续；按钮上只写一个字，悬停提示（及读屏软件）会写全「暂停 / 继续」。只在对局进行中出现；**没有「开始」按钮** —— 开表靠拍面板 |
| 🔊 / 🔇 | 声音开关（走子音 + 超时警报） |
| 180° | 对坐模式：把对面那块面板整体旋转 180°，让坐在对面的选手读正（见第五节） |
| ⇵ | 交换两侧位置：双方在屏幕上换半边 —— 竖屏「黑上白下 ⇄ 白上黑下」，横屏「黑左白右 ⇄ 白左黑右」（见第五节） |
| ⛶ | 全屏（iOS Safari 不支持网页全屏，用"添加到主屏幕"代替） |
| ⚙ | 返回设置（对局中会二次确认） |

### 键盘快捷键（在电脑上跑的时候）

| 键 | 作用 |
| --- | --- |
| `A` / `←` | 白方按键（开局前按它 → 黑方的钟开始走） |
| `L` / `→` | 黑方按键（开局前按它 → 白方的钟开始走） |
| `空格` | 暂停 / 继续（开局前按了没反应） |
| `F` | 全屏 |

## 四、计时模式与推荐配置

| 模式 | 规则 | 什么时候用 |
| --- | --- | --- |
| **Fischer 加秒**（推荐） | 每走完一步，自己钟上立即加上固定秒数 | FIDE 现行标准。10+5、15+10 最常用 |
| **Bronstein 延时** | 每步开始后的前 N 秒不计时，超过才开始扣 | 初学者、少儿赛：前几秒不会因慌张掉时间 |
| **Byoyomi 读秒** | 主时间用完后，**每一手重新给固定的 X 秒**（用不完不累积）；可设 N 段，超时一次消耗一段，段数用尽再超即判负 | 围棋 / 将棋 / 中国象棋的制式；也适合"最后阶段每步限时"的场合 |
| **无加秒** | 只有基础时间 | 最简单的突然死亡制 |

**读秒到底怎么算**（60 分钟 + 30 秒 × 3 段 为例）：

1. 主时间 60 分钟内随便想；第 1 步开始就有加秒的模式是 Fischer，读秒**不**在前期生效。
2. 主时间用尽 → 进入读秒：每一手都给满 30 秒。这手用 12 秒安全，**下一手照样是完整的 30 秒**（不累积、不结转）。
3. 某一手超过 30 秒没落子 → 消耗一段，读数重置回 30 秒继续想；「30 秒 × 3 段」意味着**允许你超时思考 2 次**，第 3 次超时就判负。
4. 界面表现：读秒阶段数字转**紫色**并显示「读秒 2/3 段」，主时间告急的琥珀色不会在此阶段出现，但最后 20 秒仍会转红；最后 10 秒每秒有滴答提示音（主时间阶段同样如此）。

> 读秒与 Bronstein 延时最容易混：Bronstein 从**第 1 步**起每步就送 N 秒；读秒是**存款花光后才开始发月薪**。

内置预设出现在一个**下拉框**里（也可自定义 1–180 分钟 / 0–180 秒读秒、1–20 段，改过数字后下拉框显示
「自定义」）——**预设会随模式切换**：

**国际象棋类模式**（Fischer / Bronstein / 无加秒）：

| 预设 | 档次 | 典型场合 |
| --- | --- | --- |
| 1+0 | 子弹 | 娱乐快赛 |
| 3+2 | 超快棋 | FIDE 超快棋标准 |
| 5+0 / 5+3 | 快棋 | 校园快棋赛 |
| **10+5** | 快棋 | **社区/校际赛推荐** |
| 15+10 | 快棋 | FIDE 快棋标准，时间充裕 |
| 25+10 / 30+0 | 慢棋 | 俱乐部联赛 |
| 60+30 | 慢棋 | 读秒制的经典配置（60 分钟 + 每步 30 秒读秒） |
| 90+30 | 慢棋 | 正式慢棋单时段近似 |

**围棋（Byoyomi）模式**——记法是「**基础时间 + 段数 × 每手秒数**」，
所以 `10+3×20` = 主时间 10 分钟，之后每手 20 秒、共 3 段（可超时思考 2 次，第 3 次判负）：

| 预设 | 读法 | 典型场合 |
| --- | --- | --- |
| 5+3×20 | 5 分钟 + 20 秒 × 3 段 | 少儿 / 快速围棋赛 |
| **10+3×20** | 10 分钟 + 20 秒 × 3 段 | **默认值**（首次打开就是这个） |
| 10+3×30 | 10 分钟 + 30 秒 × 3 段 | 校园围棋赛 |
| 15+3×30 | 15 分钟 + 30 秒 × 3 段 | 校园 / 社区赛 |
| 20+5×30 | 20 分钟 + 30 秒 × 5 段 | 标准业余赛 |
| 30+5×30 | 30 分钟 + 30 秒 × 5 段 | 俱乐部赛 |
| 30+3×60 | 30 分钟 + 60 秒 × 3 段 | 慢棋 |
| 60+5×60 | 60 分钟 + 60 秒 × 5 段 | 正式慢棋 |

> 每一档只写一次，用围棋记法：`30+5×30` 已经把主时间（30 分钟）、段数（5）、每手秒数（30 秒）都写全了，
> 下拉框不再重复另一种读法。（棋类那几档带第二段 `10+5 · Rapid`，因为那是「档次」而不是复述。）
> **第一次从别的模式切到 Byoyomi 时也会自动套用 `10+3×20`**，免得 Fischer 的 `5+3` 稀里糊涂变成
> 「5 分钟 + 每手 3 秒 × 3 段」。如果三个数字本来就正好等于某一档读秒预设（是你自己挑的），就原样保留。
> 社区和校际赛建议 **10+3×20**（默认）或 **15+3×30**：初学者不至于因为找不到棋钟按钮而瞬间掉时间。

### 围棋（Weiqi / Go）怎么用

这台棋钟**不只给国际象棋用**，围棋同样直接可用——围棋的赛制本来就是「保留时间 + 读秒」，正好是本棋钟的
Byoyomi 模式，而且**首次打开就是这套默认值**（英文 + Byoyomi + `10+3×20`）。

| 围棋常见赛制 | 本棋钟怎么设 |
| --- | --- |
| 主时间 10 分钟，之后每手 20 秒 × 3 次 | 选预设 **10+3×20**（默认值，打开即用） |
| 主时间 30 分钟，之后每手 30 秒 × 5 次 | 选预设 **30+5×30** |
| 主时间 1 小时，之后每手 60 秒 × 5 次 | 选预设 **60+5×60** |
| 主时间 40 分钟，之后每手 30 秒 × 3 次 | 预设里没有 40 分钟这一档：选 **Byoyomi** 后手动把三个数字改成 40 / 30 / 3 |
| 包干制（只有主时间，用完即负） | 选 **Sudden death（无加秒）**，或把读秒秒数设为 0（见下） |
| 纯读秒（完全没有主时间） | 把**基础时间**设为 0，读秒秒数照填 |

> **两个数各可以是 0，但不能同时是 0。** 读秒模式下这两个数是一对，只要有一个非零就能开局：
> * **基础时间 = 0** → *纯读秒*：从第一手起钟上显示的就是一格读秒，没有主时间可以消耗；
> * **读秒 = 0 秒** → *只有主时间*：主时间用完即判负（等同于包干制），数字下面那条段数条也不显示；
> * **两个都 0** 没有意义：刚改的那个字段会弹回最小值（存档里的非法组合则回落到 1 分钟主时间）。
>   其它模式（Fischer / Bronstein / 无加秒）没有第二个数兜底，基础时间仍然是 1–180 分钟。

预设下拉框里的记法是「基础时间 + 段数 × 每手秒数」，例如 `30+5×30` = 主时间 30 分钟、之后每手 30 秒共 5 段
（可以超时思考 4 次，第 5 次判负）。三个数各出现一次：主时间 → 段数 → 每手秒数。

对局时和象棋一样：手机平放在两位选手之间、开启**对坐模式**，谁下完一手就拍自己那一侧的整块面板；
开局则拍**黑方**那一半，让白方的钟先走（见第三节的比赛流程）。数字会自动撑满面板，桌子对面也看得清。
任何倒计时进入最后 10 秒都会每秒滴答一次——**主时间和读秒都算**（四种模式通用），所以围棋常用的「一手 30 秒读秒」和 3+2 快棋的收尾听起来是一样的。

## 五、摆放方式（对坐模式 · 交换两侧）

手机平放在两位选手之间，屏幕朝上：

```
        黑方选手（对面）
   ┌───────────────────────┐
   │    ███ 黑方 2:57      │  ← 上方面板内容旋转 180°，对面看是正的
   ├───────────────────────┤
   │  ▣ 180° ⇵ 停 🔊 ⛶ ⚙   │  ← 操作条：最左边是 logo，左右两侧都够得着
   ├───────────────────────┤
   │    白方 3:01 ███      │  ← 下方面板不旋转，近侧选手看是正的
   └───────────────────────┘
        白方选手（近侧）
```

* **竖屏（推荐）**：上下分屏，黑方在上、白方在下。开启「对坐模式」后，**上方面板整体旋转 180°**，对面选手看自己的数字是正的。若手机是立起来给裁判/观众看的，把对坐模式关掉即可两边都正向。
* **横屏**：左右分屏（黑左白右），**不做旋转**。因为横屏时两块面板落在同一条视线上，任何单面板旋转都无法让两位选手同时读正 —— 横屏更适合把手机立起来、或由裁判与观众查看。

开局也由面板完成：拍**对面那一半**（白先走时就是黑方那一半），对侧的钟随即开始走。没有「开始」按钮要按。

### `180°`（对坐模式）与 `⇵`（交换两侧）不是一回事

| 按钮 | 改变的是什么 | 竖屏 | 横屏 |
| --- | --- | --- | --- |
| **`180°`** | *数字朝向*：把对面那块面板整体转 180°，让对面的选手读正 | 上方面板旋转 | 不旋转（两块都要照顾，做不到） |
| **`⇵`** | *双方各占屏幕的哪一半*：两边换位置，数字朝向不变 | 黑上白下 ⇄ 白上黑下 | 黑左白右 ⇄ 白左黑右 |

* 两人对坐、需要对面那块看得正 → 用 **`180°`**：它不挪动任何人，只把对面那块面板的数字转过来。
* 双方坐错了半边（例如白方选手坐在了显示黑方的那一侧）→ 用 **`⇵`**：面板内容、拍击区域、键盘按键都跟着「方」走（`A`/`←` 永远是白方），只是屏幕上的位置互换。页面**没有重排 DOM**：两块面板是用 CSS `order` 排的，所以竖屏横屏都同样有效。
* 两者互不影响、可以叠加：开着对坐模式时，**交换过之后被旋转的就是另一块面板**（竖屏），因为被旋转的永远是视觉上排在最前的那一块。
* 这个选择和其他设置一起存在 `localStorage` 里，所以**再来一局**、切语言、换主题都不会把它重置。

## 六、裁判须知与已知限制（重要，请先读）

1. **超时判罚的边界**：本棋钟只负责"时间到 → 停表 → 提示"，**不判断局面**。按 FIDE 规则 6.9，若超时一方的对手"无法以任何合法着法序列将杀"（例如王对王、王单马、王单象），该局应判**和棋**而不是判负。覆盖层给的是"超时/获胜"，最终判罚请裁判根据局面宣布。
2. **一格设备只能下一盘**：两个浏览器页面之间**没有**时间同步。一盘棋用一台设备。
3. **后台/息屏不会算错时间**：手机息屏或被切到后台时，浏览器会限流甚至冻结定时器。本棋钟的所有显示与判负都基于**绝对时间戳**推算（"已入账时间 − 本手开始时刻"），所以回到前台时会立刻得到正确结果与正确的超时方 —— 最多"晚发现 1 秒"，不会多送或少算时间。这一点有单元测试覆盖。
4. **来电、通知、误触**：建议比赛时开飞行模式或免打扰、关掉弹窗通知；对局中刷新/关页面会有二次确认。误触方面：整块面板就是按键，所以请把手机放稳（不要放在棋盘边缘），并确认"按在非走棋方"不会产生任何效果（已如此实现）。
5. **电量与亮度**：建议插充电宝，亮度调高（户外）。对局中已自动申请屏幕常亮（Wake Lock），但 iOS 16.4 以下、部分浏览器不支持，此时请手动把自动锁屏设为"永不"。
6. **浏览器要求**：iOS 13+ / Android Chrome 55+（需要 Pointer Events）。桌面 Chrome / Edge / Firefox / Safari 均可。
7. **隐私**：不联网、不上传任何数据，设置（模式/时间/声音）只存在本机 `localStorage`。
8. **读秒的判负依据**：读秒模式下是"**读秒段数用尽**"而不是主时间归零。面板步数那一行会显示「读秒 2/3 段」，**数字下方、步数行上方的分段指示条**把同一件事说成一眼就看懂的样子——3 格 = 3 段，正在倒计时的那一格会随着读秒时间流逝由绿变红（剩 5/20 秒就是 75% 红），用完就整格变红，只剩一格还有绿的时候请格外留意。裁判按暂停会先结算已经跨过的段数，恢复后当前那个读秒窗口重新满格（不会让选手白丢读秒）。
9. **怎么开局**：没有「开始」按钮 —— **拍面板就是开局动作**（白先走就拍黑方那一半）。赛前先约定由谁拍，并注意这第一下**不算步数**，所以两边的步数仍然显示 0。

### 界面主题（浅色 / 中性 / 深色）

设置页「3. 选项」里有一个**界面主题**下拉框，三选一：浅色 / 中性（石板灰）/ 深色（默认）。
选择同样存在 `localStorage`，也能用 `index.html?theme=light`（或 `medium` / `dark`）直接指定。

实现方式：主题只是一组 CSS 变量。`styles.css` 顶部有三块

```css
:root, :root[data-theme="dark"] { --bg: …; --fg: …; --card: …; --accent: … }
:root[data-theme="medium"] { … }
:root[data-theme="light"]  { … }
```

切换时 `app.js` 只做一件事：给 `<html>` 打上 `data-theme="…"`（顺带把手机浏览器地址栏的
`theme-color` 设成当前 `--bg`）。**两块对局面板始终是「黑方深、白方浅」**——那是棋局语义，不随主题变；
浅色主题下白方面板会自动加一圈细边（`--pane-edge`），免得和页面底色糊在一起。

* 想微调某个主题：只改对应的变量块即可（`--card`/`--sunken`/`--btn` 分别是卡片、凹陷槽、按钮底色）；
* 想加第四套主题：`styles.css` 加一块变量 + `app.js` 的 `THEMES` 加一项 + `index.html` 加一个
  `<option value="…">` + `i18n.js` 加词条（测试会核对这四处是否一一对应）；
* 首屏不闪：`<head>` 里有一段内联脚本，在页面绘制前就把存档里的主题打到 `<html>` 上
  （否则选了浅色的人每次打开都会先闪一下深色）。

### 想恢复出厂默认值？

> 换图也只需要换一个文件。

想调显示尺寸：改 `styles.css` 里 `.brand-logo` / `.strip-logo` 的 `width/height`、
`index.html` 上对应的 `width`/`height`，以及脚本里的 `JOBS` 尺寸，测试会一起核对。
