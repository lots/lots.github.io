Dataset review

围棋词典 · Go Dictionary

A portable manager for Chinese–English Go terms and proverbs. It runs straight from a USB stick — no server, no install, no network.

Two sections 两部

  • 围棋术语 Terms — 721 merged rows or the 630-row base extraction, with source, notes and definitions.
  • 围棋棋谚 Proverbs — 97 sourced sayings with pinyin, English, Chinese explanation and provenance.
  • Each section autosaves separately and exports its own JSON/CSV file.

Everyday use

  • Click a row to edit; N adds a term or proverb.
  • Ctrl+K or / jumps to search.
  • Ctrl+Z undoes; Ctrl+Y redoes.
  • Use the tabs to move between 术语 and 棋谚.

Saving to the USB stick

  • Save JSON writes the active section's file in place in Chrome/Edge (choose it once).
  • Otherwise use Download JSON and copy the file beside the project.
  • CSV is for spreadsheets. Media is kept in JSON and PDF, not CSV.

PDF 打印

  • PDF opens a print-ready dictionary of the current term edition plus all proverbs.
  • Press the preview's Print / Save as PDF button (or Ctrl+P), then choose Save as PDF.
  • A4 portrait, repeating table headers, bilingual columns; images and SGF diagrams are included.

Diagrams 图示

  • Attach PNG, JPG, GIF or WebP to a term or proverb. GIFs stay animated.
  • SGF files are rendered as a board preview of the first main line.
  • Media lives in the JSON export; keep files small (localStorage is limited).

Data rules

  • Leave traditional empty when it matches the simplified form.
  • Separate multiple English senses with semicolons; proverbs use one sentence.
  • Pinyin uses tone marks; the plain, searchable form is derived.
  • Merged terms and proverbs are personal reference material — see the sources in README.md.
